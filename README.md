One emoji that stands for my AI agent: 🧞 — a genie. Summoned on call, it grants the wish by doing the work itself: the agent's character in a single glyph. It reads instantly at small size, says something specific about how the agent works, and stays far from the obvious robot or smiley.

## Run it

```sh
node main.ts
```

It writes the glyph to `/output/entry.txt`.
